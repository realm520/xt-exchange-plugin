安装

在 Claude Code 中执行两条命令完成安装：

claude plugin marketplace add realm520/xt-exchange-plugin
claude plugin install xt-exchange@realm520-xt-exchange-plugin

API Key 配置

1

在 XT.COM 创建 API Key

登录 XT.COM API 管理页面，创建新 Key 并勾选权限：

权限用途建议
Read行情 / 余额 / 订单查询必须开启
Trade下单 / 撤单 / 开平仓按需开启
Transfer账户间划转按需开启
Withdraw提币到外部地址谨慎开启
2

保存凭证到本地

将 Access Key 和 Secret Key 写入凭证文件：

Bash 
mkdir -p ~/.xt-exchange
cat > ~/.xt-exchange/credentials.json << 'EOF'
{
  "access_key": "your_access_key_here",
  "secret_key": "your_secret_key_here"
}
EOF
chmod 600 ~/.xt-exchange/credentials.json
3

或让 Claude 引导你完成

直接输入 /xt-exchange，当你请求需要认证的操作时，Claude 自动检测凭证是否存在，若缺失则逐步引导你输入并安全保存。

💡
也可通过环境变量临时传入：XT_ACCESS_KEY=xxx XT_SECRET_KEY=yyy $PYTHON $SPOT balance，适合一次性使用或 CI 场景。Secret Key 不会在对话中回显。

现货交易

现货接口对接 sapi.xt.com。行情查询无需 API Key，账户与交易操作需要认证。

行情查询（无需 API Key）

操作命令示例说明
最新价格ticker btc_usdt实时最新成交价
24H 行情ticker_24h btc_usdt开/高/低/收、涨跌幅、成交量
盘口深度depth btc_usdt --limit 10买卖盘挂单列表
K 线数据klines btc_usdt --interval 1h支持 1m / 5m / 15m / 1h / 4h / 1d
交易对信息symbol btc_usdt精度、最小下单量、支持的链
Bash — 行情示例 
$PYTHON $SPOT ticker     btc_usdt
$PYTHON $SPOT ticker_24h eth_usdt
$PYTHON $SPOT depth      btc_usdt --limit 20
$PYTHON $SPOT klines     btc_usdt --interval 4h --limit 48
$PYTHON $SPOT symbol     usdt         # 查询 USDT 支持的提币链

账户操作（需要 API Key）

操作命令示例说明
全部余额balance所有非零币种余额 + 折合 USDT
单币余额balance usdt指定币种可用与冻结量
当前挂单orders所有未成交挂单
历史订单history --limit 20最近成交 / 撤销的记录
Bash — 账户示例 
$PYTHON $SPOT balance              # 全部非零余额
$PYTHON $SPOT balance usdt         # 单币查询
$PYTHON $SPOT orders               # 当前挂单
$PYTHON $SPOT history --limit 50

下单 / 撤单（需要 API Key + 确认）

操作命令示例
限价买入buy btc_usdt --price 95000 --qty 0.001
限价卖出sell btc_usdt --price 98000 --qty 0.001
市价买入（指定金额）buy btc_usdt --market --quote_qty 500
市价卖出sell btc_usdt --market --qty 0.001
撤销指定订单cancel --id 123456789
一键撤全部cancel_all
Bash — 下单示例 
# 限价单
$PYTHON $SPOT buy  btc_usdt --price 95000 --qty 0.001
$PYTHON $SPOT sell btc_usdt --price 98000 --qty 0.001

# 市价单（买入指定 USDT 金额）
$PYTHON $SPOT buy btc_usdt --market --quote_qty 500

# 撤单
$PYTHON $SPOT cancel --id 123456789
$PYTHON $SPOT cancel_all

资产管理（划转 & 提币）

🚨
提币不可撤销。执行前 Claude 会展示完整信息（币种、链名、数量、手续费、预计到账量、完整目标地址）并要求二次确认。
Bash — 资产管理 
# 账户划转
$PYTHON $SPOT transfer --from SPOT --to FUTURES_U --currency usdt --amount 500
$PYTHON $SPOT transfer --from FUTURES_U --to SPOT --currency usdt --amount 100

# 提币（chain 名称可通过 symbol 命令查询）
$PYTHON $SPOT withdraw --currency usdt --chain "Ethereum"   --amount 200 --address 0xABC...
$PYTHON $SPOT withdraw --currency pol  --chain "Polygon POS" --amount 100 --address 0xDEF...

账户类型（--from / --to）：

类型说明
SPOT现货账户
LEVER杠杆账户
FUTURES_UUSDT 本位合约账户
FUTURES_C币本位合约账户
FINANCE理财账户

合约交易

合约接口对接 fapi.xt.com，支持 USDT-M 永续合约，数量单位为张（整数），最小 1 张。

📌
合约面值参考：BTC = 0.001 BTC / 张，ETH = 0.01 ETH / 张。下单请注意换算。

行情查询（无需 API Key）

Bash — 合约行情 
$PYTHON $FUTURES ticker       btc_usdt   # 最新价、涨跌幅、成交量
$PYTHON $FUTURES depth        btc_usdt   # 合约盘口深度
$PYTHON $FUTURES funding_rate btc_usdt   # 资金费率 & 下次结算时间
$PYTHON $FUTURES klines       btc_usdt --interval 1h --limit 48

账户 & 持仓（需要 API Key）

Bash — 合约账户 
$PYTHON $FUTURES account                   # 账户权益、保证金、未实现盈亏
$PYTHON $FUTURES positions                  # 当前所有持仓
$PYTHON $FUTURES orders                     # 当前委托列表
$PYTHON $FUTURES history --limit 20         # 历史委托记录

开仓 / 平仓（需要 API Key + 确认）

Bash — 开平仓示例 
# 开多（限价）
$PYTHON $FUTURES open_long  btc_usdt --qty 1 --price 95000

# 开空（市价）
$PYTHON $FUTURES open_short btc_usdt --qty 1 --market

# 平多（市价平仓）
$PYTHON $FUTURES close_long btc_usdt --qty 1 --market

# 撤销委托
$PYTHON $FUTURES cancel --id 987654321

安全机制

✅
所有写操作（下单、撤单、划转、开平仓）执行前均展示完整参数，等待用户输入「确认」「yes」「对」后才执行。

确认机制对照

操作类型确认级别展示内容
下单 / 撤单一次确认交易对、方向、价格、数量
账户划转一次确认来源账户、目标账户、币种、金额
开仓 / 平仓一次确认合约、方向、张数、价格
提币二次确认币种 / 链名 / 数量 / 手续费 / 到账量 / 完整地址 + 不可逆警告

凭证安全

  • 凭证文件权限 600（仅本人可读），Secret Key 不在对话中回显
  • 支持环境变量 XT_ACCESS_KEY / XT_SECRET_KEY 临时传入
  • 建议只开启实际需要的 API 权限，提币权限按需开启

故障排除

❌ 提示"需要 API Key"

检查凭证文件是否存在且格式正确：

Bash 
cat ~/.xt-exchange/credentials.json
ls -la ~/.xt-exchange/credentials.json   # 确认权限为 -rw-------

❌ 依赖未安装 / Python 找不到

Bash 
cd "$CLAUDE_PLUGIN_ROOT"
python3 -m venv .venv
.venv/bin/pip install requests

❌ API 错误 [INVALID_SIGN]

  • Access Key / Secret Key 复制时含多余空格或换行
  • 系统时间与 XT 服务器时差超过 60 秒，请同步本机时间
  • API Key 未开启对应权限（Trade / Transfer / Withdraw）

❌ 合约下单精度错误

合约数量必须为整数（张），最小 1 张。--qty 0.5 无效，应传 --qty 1。
